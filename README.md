# ReliveRS — Portfolio técnico

Portfolio personal de **Rafael Segura Orta**, desarrollado para presentar mi perfil en desarrollo de software, sistemas y ciberseguridad.

Incluye una experiencia visual interactiva basada en React, TypeScript y Three.js, con un modo de lectura rápida pensado para recruiters.

## Perfil

Técnico Superior en Desarrollo de Aplicaciones Multiplataforma, con experiencia en sistemas Core Banking y una base técnica en electrónica, automatización y diagnóstico de incidencias.

Áreas principales:

- Desarrollo Android con Kotlin y Jetpack Compose
- Backend con Java y Spring Boot
- APIs REST, JWT y JPA/Hibernate
- SQL, PostgreSQL, MySQL, Oracle y modelado de datos
- Docker, AWS EC2 e integración continua
- Sistemas, redes y ciberseguridad

## Características

- Portfolio responsive para escritorio, tablet y móvil
- Mapa interactivo de tecnologías en el hero
- Tech Galaxy, Soft Skills Galaxy y Foundation Galaxy
- Navegación visual entre universos con transiciones warp
- Recruiter Mode: resumen profesional de lectura rápida
- Modal de arquitectura para el proyecto RecordNote
- Soporte para `prefers-reduced-motion`
- Estados de foco y navegación accesibles

## Ejecutar en local

### Requisitos

- Node.js 20 o superior
- npm

### Instalación

```bash
git clone https://github.com/ReliveRS/portfolio-relivers.git
cd portfolio-relivers
npm install
```

### Desarrollo

```bash
npm run dev
```

Abre la URL que muestra Vite en la terminal, normalmente:

```text
http://localhost:5173
```

### Build de producción

```bash
npm run build
```

El resultado se genera en la carpeta `dist/`.
